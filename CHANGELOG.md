# Changelog

## 26.1.0

- Convert polygon datasets among Shapefile, KML, KMZ, and supported CAD sources.
- Transform coordinates to a selected output CRS.
- Transfer selected source attributes to converted outputs.
- Map CAD layers and optionally associate contained CAD text with polygons.
- Preserve multipart polygon geometry and validate created outputs.
- Protect existing destinations from accidental replacement.
- Display live conversion progress from 0 to 100 percent.
- Include synthetic sample data and usage documentation.
