# Synthetic sample data

- `polygons.kml`: two simple WGS 84 polygons with `name` and `category`
  attributes. Use it for the quickest KML-to-SHP/KMZ/DXF check.
- `boundaries.dxf`: two closed DXF rectangles on the `BOUNDARY` layer and
  labels on the `OWNER` layer. Driver behavior depends on the GDAL build in
  QGIS.

These files contain no real people, parcels, or survey data.
